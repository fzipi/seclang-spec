# Specification Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the spec chapters, the compatibility pages (known gaps, matrix) and the ADRs as a Hugo site built from the repository markdown and deployed to GitHub Pages.

**Architecture:** A `site/` directory with Hugo configuration only. Module mounts expose `../spec`, `../compat` and `../adr` as assets; one content adapter per section turns each markdown file into a page (title from the first heading, weight from the numeric prefix). Hextra is the theme, pulled as a Hugo module. A workflow builds on pull requests and deploys on pushes to `main`.

**Tech Stack:** Hugo 0.166.0 extended, Hextra v0.13.0 (Hugo module, needs Go), GitHub Pages actions.

**Spec:** `docs/superpowers/specs/2026-10-07-hugo-site-design.md`

## Global Constraints

- No repository markdown is copied into `site/content`; adapters read the mounted sources.
- Hextra pinned to v0.13.0 in `site/go.mod`; Hugo pinned to 0.166.0 in the workflow.
- Link hook: `markup.goldmark.renderHooks.link.useEmbedded: fallback`.
- `adr/README.md` becomes the Decisions section index; `adr/0000-template.md` is not published.
- `site/public` and `site/resources` are git-ignored.
- Every commit ends with the two attribution lines used throughout this repository.

## Review Focus

1. A spec link with an anchor (`03-processing-model.md#chains`) must keep the anchor on the resolved URL (Task 1 smoke check `anchor`).
2. The ADR template must not appear in the Decisions section (Task 1 smoke check `template`).
3. The known-gaps table must render as an HTML table with its header row (Task 1 smoke check `gaps-table`).
4. A chapter title must come from the heading, not the filename (Task 1 smoke check `title`).
5. The deploy job must never run on a pull request (Task 3: `if: github.event_name == 'push'`).

# site/smoke.sh — run after `hugo -s site`; exits non-zero on the first missing property.
#!/bin/sh
set -eu
P="$(dirname "$0")/public"
check() { name=$1; shift; if "$@" >/dev/null 2>&1; then echo "ok   $name"; else echo "FAIL $name"; exit 1; fi; }
check pages        test -f "$P/spec/06-operators/index.html" -a -f "$P/compat/known-gaps/index.html" -a -f "$P/compat/matrix/index.html" -a -f "$P/adr/0024-ipmatch-invalid-entries/index.html" -a -f "$P/adr/index.html"

check anchor       grep -q 'href="[^"]*/spec/03-processing-model/#chains"' "$P/spec/08-actions/index.html"
check adr-index    grep -q 'href="[^"]*/adr/0023-reference-adapters/"' "$P/adr/index.html"
check template     test ! -e "$P/adr/0000-template"
check gaps-table   grep -q '<th>Behaviour today</th>' "$P/compat/known-gaps/index.html"
check no-md-links  sh -c "! grep -rqo 'href=\"[^\"]*\.md[^\"]*\"' '$P/spec' '$P/adr' '$P/compat'"

Adapter template, identical for the three sections except the source glob (`src/spec`, `src/compat`, `src/adr`):

```
{{/* site/content/spec/_content.gotmpl */}}
{{ range resources.Match "src/spec/*.md" }}
  {{ $name := path.BaseName .Name }}
  {{ if ne $name "0000-template" }}
    {{ $raw := .Content }}
    {{ $title := $name }}
    {{ with findRESubmatch `(?m)^# (.+)$` $raw 1 }}{{ $title = index (index . 0) 1 }}{{ end }}
    {{ $body := replaceRE `(?m)^# .+\n` "" $raw 1 }}
    {{ $weight := 999 }}
    {{ with findRE `^\d+` $name 1 }}{{ $weight = int (strings.TrimLeft "0" (index . 0) | default "0") }}{{ end }}
    {{ $path := $name }}
    {{ if eq $name "README" }}{{ $path = "_index" }}{{ end }}
    {{ $.AddPage (dict
        "path" $path
        "title" $title
        "weight" $weight
        "content" (dict "mediaType" "text/markdown" "value" $body)
    ) }}
  {{ end }}
{{ end }}
```

Create the three files with `for d in spec compat adr; do sed "s#src/spec#src/$d#" > site/content/$d/_content.gotmpl; done` from the spec version. The `adr` section has no `_index.md`: `README.md` becomes it.

Module files: `cd site && hugo mod init github.com/fzipi/seclang-spec/site && hugo mod get github.com/imfing/hextra@v0.13.0 && hugo mod tidy`.

`.gitignore`: append `site/public/` and `site/resources/`.

### Task 3: Pages workflow

**Files:**
- Create: `.github/workflows/pages.yml`
- Modify: `README.md` (link to the site)

- [ ] **Step 1: Write the workflow**

```yaml
name: pages
on:
  push:
    branches: [main]
  pull_request:
permissions:
  contents: read
concurrency:
  group: pages
  cancel-in-progress: false
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: stable
      - uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: "0.166.0"
          extended: true
      - id: pages
        if: github.event_name == 'push'
        uses: actions/configure-pages@v5
      - run: hugo -s site --gc --minify --baseURL "${{ steps.pages.outputs.base_url || 'https://example.invalid' }}/"
      - run: site/smoke.sh
      - if: github.event_name == 'push'
        uses: actions/upload-pages-artifact@v3
        with:
          path: site/public
  deploy:
    if: github.event_name == 'push'
    needs: build
    runs-on: ubuntu-latest
    permissions:
      pages: write
      id-token: write
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```
